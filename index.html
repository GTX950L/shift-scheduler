💡 操作指引

① 添加技术员：设置部门、班次规则（固定白班 / 固定夜班 / 月轮转）、休息规则。
② 点「⚡ 自动排班」生成当月排班基线。
③ 微调：点击格子循环切换 休→白→夜；Shift+点击 加班；Alt+点击 留守；按住拖拽批量填充；右键菜单（休/请假/清除手动）；Ctrl+Z/Y 撤销/重做。
📋 复制排班：右侧人员卡片点「📋」选源 → 点目标人员卡片 → 当月排班整体复制（含休），可 Ctrl+Z 撤销。
⌨ 快捷键：1循环 2白 3夜 4休 5加班 6留守；←→或PgUpPgDn 切换月份。
④ 周末负荷：周六/周日可设「繁忙 / 正常 / 低负荷」——繁忙=休息者叫回加班；低负荷=按部门保底留人（默认 除气白2 + 转码白1夜1，固定班优先，其余休）。
⑤ 留守模式：低负荷时每天仅保留白班2人/夜班1人（全员轮换）。
⑥ 转班：默认每月最后一个周末（周六起）白夜互换；可选「固定日期」；「视图」切跨月可连续看转班前后几天。
⑦ 连班保护：任何人「夜班→次日白班」都会自动插一天休息（0 小时间隔禁止，转班点必歇）；白班→夜班（16h）允许。
⑧ 体检与节假日：「🔍 体检」一键查连班/连续上班/班次空缺/节假日值班；「🏮 节假日」标记法定假日与停线日。
⑨ 用旧表改新表：「⬆ 导入 ▾」导入旧排班 CSV → 按提示清空 → 重新「自动排班」。

❓ 使用说明

📌 排班流程

  • 先「＋ 添加」技术员：姓名、部门（除气/转码）、班次规则、休息规则。
  • 点「⚡ 自动排班」生成当月基线；之后随时可再点，手工改过的格子不会被覆盖（格子左上角蓝点 = 手动修改）。
  • 每格左侧小点含义：🔴加班 🔵留守。

✍️ 手工微调

  • 选择「画笔」后点击 / 按住拖拽批量填充：白班 / 夜班 / 休 / 加班 / 留守。
  • 「🔁 循环切换」画笔：点击依次 休 → 白班 → 夜班 → 休。
  • 快捷键：1~6 切换画笔（循环/白/夜/休/加班/留守）；Shift+点击=加班，Alt+点击=留守，右键=弹出菜单（休息 / 请假 / 清除手动）。
  • Ctrl+Z / Ctrl+Y（或工具栏 ↩ ↪）撤销 / 重做；←→ 或 PgUpPgDn 切换中心月份。
  • 复制排班：右侧技术员卡片点「📋」→ 再点另一张卡片，把源人员当月排班整体复制给目标（含休息日，可 Ctrl+Z 撤销）；点空白处取消。

📝 请假 / 🏮 节假日

  • 排班表任意格子右键 → 请假（事假/病假/年假/其他），格子变灰显示「假」，统计/合计自动计入请假、出勤排除；右键「取消请假」销假。
  • 「🏮 节假日」按钮可给任意日期标记法定假日/停线日：表头显示 🏮+名称、列淡黄高亮。

🔍 排班体检

  • 一键检查当前月：夜→白连班（红框+⛔）、最长连续上班超 7 天（⚠️）、某天无人上班（⛔）、节假日无人值班（⚠️）。
  • 修改任意违规格子后红框自动清除；「清除红框标记」可一键清空。

⚖️ 周末与人力

  • 周六 / 周日负荷设为「繁忙」：自动排班时双休人员该日改为上班并标记加班。
  • 设为「低负荷」：按部门保底留人——除气白班2人（固定班优先，如周洪发）+ 转码白班1人/夜班1人，其余休息；可配合「留守模式」使用。
  • 设为「繁忙」：休息的双休/上六休一人员被叫回加班。
  • 「留守模式」：每天只保留白班2人 + 夜班1人（名单轮换），其余休息，适合无任务时线上留守。

📅 跨月连续查看

  • 工具栏「视图」切换显示范围：本月 / 上月+本月 / 上月+本月+下月（默认跨 3 个月连续滚动）。
  • 跨月视图下月底与下月初连在一起，可直接观察转班那几天的人员衔接。
  • 表头显示真实日期与星期，月初列标出月份（如「9月」）；双击任一日期列 = 把前一天的排班复制到该日（跨月自动衔接）。
  • 统计 / 图表 / CSV 导出均针对当前中心月。

🔁 转班

  • 默认「月末周末」：轮转人员每月最靠近月末的周六起白夜互换（周六、周日完成转班），跨月视图可直观看到衔接。
  • 也可在工具栏改为「固定日期」并设 1~31 号（如 20 = 每月 20 日起换班）。
  • 连班保护（全员）：任何人「夜班 → 次日白班」都是 0 小时间隔连班，自动排班会自动在转班点插入一天休息；「白班 → 次日夜班」（16 小时间隔）允许，不处理。周末繁忙叫回的加班同样受此保护。
  • 固定班次者不受转班影响；某月想破例可用「🔁 本月转班」强制取反，再手工微调。

📄 导入旧排班表（改新表流程）

  • 工具栏「⬆ 导入 ▾ → 排班表 CSV」选择旧表（本工具导出的格式，或 姓名+日期列 的通用表格）。
  • 导入后旧排班会按人员锁定（格子左上角蓝点），人员按姓名合并：同名更新属性、新名新增。
  • 旧表不想用了想重新排：导入完成后按提示点「确定」清空旧排班 → 点「⚡ 自动排班」生成新表 → 再手工微调。
  • 想保留旧表只改部分：直接点格子修改，或「🧹 清手动」后重新自动排班。

💾 数据

  • 所有数据自动保存在本机浏览器（localStorage），关闭页面不丢失。
  • 「⬇ 导出 ▾ → 排班表 CSV」导出当月排班（Excel 可开）；「→ 完整备份 JSON」备份全部数据。
  • 换电脑 / 换浏览器：导出 JSON 备份 → 新电脑「⬆ 导入 ▾ → 完整备份 JSON」恢复（会覆盖当前数据）。

标记后表头显示 🏮、列淡黄高亮；体检会检查节假日是否有人值班。
