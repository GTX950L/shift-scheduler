💡 操作指引

① 添加技术员：设置姓名、工号（选填）、部门、班次规则（固定白班 / 固定夜班 / 月轮转）、休息规则（上六休一可选周六/周日休）。
② 点「⚡ 自动排班」生成当月排班基线，并自动体检（有问题直接弹报告）。
③ 微调：点击格子循环切换 休→白→夜（悬停可预览）；Shift+点击 加班；按住拖拽批量填充；点选格子后可用 ←→↑↓ 移动、空格 循环、1~5 设值；右键菜单（休/请假/清除手动）；Ctrl+Z/Y 撤销/重做。
④ 更多功能：周模板（点表头「第N周」，按周一~周日分组）、复制排班（人员卡片「📋」）、调整行序（拖人名行）、周末负荷（周六/周日下拉）、转班、节假日、导入旧表——详见「❓ 帮助」。

❓ 使用说明

📌 排班流程

  • 先「＋ 添加」技术员：姓名、工号（选填）、部门（除气/转码）、班次规则、休息规则；上六休一可再选休息日（周六/周日）。
  • 点「⚡ 自动排班」生成当月基线；之后随时可再点，手工改过的格子不会被覆盖（格子左上角蓝点 = 手动修改）。
  • 切到尚未排班的月份会自动提示「一键排班」；点「自动排班」后自动体检——无问题提示通过，有问题直接弹出报告。
  • 格子上方标记：🔵蓝点手动修改 「加」加班。

✍️ 手工微调

  • 选择「画笔」后点击 / 按住拖拽批量填充：白班 / 夜班 / 休 / 加班。
  • 「🔁 循环切换」画笔：点击依次 休 → 白班 → 夜班 → 休；鼠标悬停格子会预览点击将变为的班次（含防呆拦截提示），看清再点。
  • 快捷键：1~5 切换画笔（循环/白/夜/休/加班）；Shift+点击=加班，右键=弹出菜单（休 / 请假 / 清除手动）。
  • 键盘微调（v1.42）：点击选中格子后（蓝色虚线框）可用 ←→↑↓ 移动焦点、空格 / Enter 循环切换、1~5 直接设值（1=循环 2=白 3=夜 4=休 5=加班）、Delete 清除手动、Esc 取消选中；未选中格子时 ←→ 仍是切换月份。
  • Ctrl+Z / Ctrl+Y（或工具栏 ↩ ↪）撤销 / 重做；PgUpPgDn 切换中心月份。
  • 复制排班：右侧技术员卡片点「📋」→ 再点另一张卡片，把源人员当月排班整体复制给目标（含休息日，可 Ctrl+Z 撤销）；点空白处取消。
  • 整月复制：工具栏「📋 复制到下月」把本月全部手工修改（请假/调班/锁定班次）复制到下月，轮转班次自动生成，可 Ctrl+Z 撤销。
  • 清除下月：工具栏「🧹 清下月」一键清除下月所有手工排班，恢复未排班状态（可 Ctrl+Z 撤销），与「复制到下月」对称。
  • 周模板复制：表头按日历周（周一到周日）分组，点「第 N 周」弹出目标周选择框——默认勾选后续所有完整周，可取消个别周后再复制（跨月周可用，复制目标跨月连续；含手工修改与休息；目标周现有手工会被覆盖，弹窗中标出「已有 N 格」供参考；模板含连班/超 6 连班的人员自动跳过；灰色周为视图截断的不完整周，不可作模板；可 Ctrl+Z 撤销）。
  • 调整行顺序：排班表按住人名行上下拖动即可换位（自动保存，跨月视图同样生效）；点表头「🔄 部门排序」恢复默认（除气在上、转码在下）。

📝 请假 / 🏮 节假日

  • 排班表任意格子右键 → 请假（事假/病假/年假/其他），格子变灰显示「假」，统计/合计自动计入请假、出勤排除；右键「取消请假」销假。
  • 「🏮 节假日」按钮可给任意日期标记法定假日/停线日：表头显示 🏮+名称、列淡黄高亮；弹窗内「📅 一键标记 2026 法定假日」按国务院放假安排批量标记（已有其他名称的日期不覆盖）。

🔍 排班体检

  • 一键检查当前月：夜→白连班（红框+⛔）、最长连续上班超 7 天（⚠️）、某天无人上班（⛔）、节假日无人值班（⚠️）。
  • 「🔧 自动修复连班」：把「夜班→次日白班」连班的次日批量改为休息（可 Ctrl+Z 撤销）。
  • 修改任意违规格子后红框自动清除；「清除红框标记」可一键清空。

⚖️ 周末与人力

  • 周六 / 周日负荷设为「繁忙」：自动排班时双休人员该日改为上班并标记加班。
  • 上六休一者的休息日（周六/周日错峰）不被繁忙覆盖，保证每周休 1 天。
  • 六休一防呆：手动排班时，上六休一人员若设置后会产生第 7 个连续工作日（任意连续 7 天窗口最多 6 天上班，含跨月、请假视为休），该格会自动改为休并提示。

📅 跨月连续查看

  • 工具栏「视图」切换显示范围：本月 / 本月+下月（默认） / 上月+本月 / 上月+本月+下月。
  • 跨月视图下相邻月底与月初连在一起，可直接观察转班那几天的人员衔接。
  • 表头显示真实日期与星期，月初列标出月份（如「9月」）；双击任一日期列 = 把前一天的排班复制到该日（跨月自动衔接）。
  • 表格较宽时，排班表上下均有横向滚动条（表上部滚动条与主表同步联动），右侧日期一目了然。
  • 统计 / 图表 / CSV 导出均针对当前中心月（CSV 文件名会标注「跨月」以提示当前视图）；打印内容跟随视图——跨月视图打印前会询问「按当前视图打印」还是「切到本月打印单月」。

🔁 转班

  • 默认「月末周末」：轮转人员每月最靠近月末的周六起白夜互换（周六、周日完成转班），跨月视图可直观看到衔接；范例（9 月）已按此排定（8/31 转班完成，仅组长因人员调整于 9/7 白班转夜班）。
  • 也可在工具栏改为「固定日期」并设 1~31 号（如 20 = 每月 20 日起换班）。
  • 连班保护（全员·防呆）：任何人「夜班 → 次日白班」都是 0 小时间隔连班，自动排班会自动在转班点插入一天休息；「白班 → 次日夜班」（16 小时间隔）允许，不处理。周末繁忙叫回的加班同样受此保护。
  • 手动防呆：手工点击 / 拖拽 / 复制时，若会产生「夜班→次日白班」连班会被拦截——夜班后一天只能设「休」或「夜」；循环画笔会自动跳过违规班次。
  • 「🔁 转班 ▾」两种方式：① 月轮转全员转班（作用于「月轮转」人员，整月强制取反）；② 📌 人员指定转班日——任意人员（含固定班）设定「从本月某日起换班」，仅当月生效，休息日与连班防呆自动套用；「月轮转」人员将以指定日替代「月末周末」自动转班，固定班人员不必再逐格手刷。

📄 导入旧排班表（智能识别）

  • 工具栏「⬆ 导入 ▾ → 排班表 CSV」选择旧表。支持多种格式：本工具导出的 CSV、带标题行/双行表头的手工排班表（如「资材部-9月-6休1排班表」）、姓名+日期列的通用表。
  • 自动识别：标题行 / 表头行 / 星期行 / 负责人行自动跳过，无需手动指定哪一行是表头。
  • 日期列：支持 第N天 / N / 8/1 / 2026/8/1 / 8月1日 / 8-1；跨月表（如 8/1~9/30）自动拆分写入对应月份。
  • 单元格文本：休/休息/空、白班/白/日/早班、夜班/夜/晚/中班、加班/加/OT、班/上/√/出勤（按该行班次自动推断白/夜）、请假（事假/病假/年假 自动登记到请假记录）。
  • 导入后旧排班会按人员锁定（格子左上角蓝点），人员按姓名合并：同名更新属性、新名新增（工号一并带入）。
  • 旧表不想用了想重新排：导入完成后按提示点「确定」清空旧排班 → 点「⚡ 自动排班」生成新表 → 再手工微调。
  • 想保留旧表只改部分：直接点格子修改，或「🧹 清手动」后重新自动排班。

💾 数据

  • 所有数据自动保存在本机浏览器（localStorage），关闭页面不丢失。
  • 「⬇ 导出 ▾」：排班表 CSV（含真实日期+星期行，Excel 可直接看）/ 月度统计 CSV（白/夜/加班/请假/出勤，月底报工用）/ 完整备份 JSON（备份全部数据）。
  • 工具栏「部门」下拉可只查看除气/转码的排班（月度统计与导出仍为全部人员）。
  • 换电脑 / 换浏览器：导出 JSON 备份 → 新电脑「⬆ 导入 ▾ → 完整备份 JSON」恢复（会覆盖当前数据，导入前有确认）。
  • 🔒 防呆保护：删除人员 / 清手动 / 强制转班 / 导入覆盖 等破坏性操作均有确认提示；人员同名会提醒、工号重复会拦截；CSV 支持 GBK/UTF-8 自动识别；导出/打印前会检查是否存在连班违规。
  • ⏪ 自动快照：删除人员 / 导入 / 示例覆盖等不可撤销操作前自动保存完整数据（最近 5 份），工具栏「⏪ 快照」可一键恢复；点「↩ 恢复」先弹差异预览（人员名单 / 手工排班格数 / 请假条数 / 受影响月份），看清影响面再确认（恢复前会再存一份当前数据）。
  • ⚡ 自动闭环：切到尚未排班的月份会自动引导「⚡ 自动排班」；点「自动排班」后自动体检——无问题提示通过，有问题直接弹出报告。
