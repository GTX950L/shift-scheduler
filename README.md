# 🗓️ 技术员排班助手

> 为除气 / 转码两部门、两班倒（白班 08:00–20:00 / 夜班 20:00–08:00）设计的月度排班工具。  
> 纯单文件 HTML，离线可用，数据存浏览器本地。

🔗 **在线使用**：<https://gtx950l.github.io/shift-scheduler>

## ✨ 核心功能

| 功能 | 说明 |
| --- | --- |
| 👷 人员管理 | 按部门（除气 / 转码）建档，姓名、班次规则、休息规则、备注 |
| 🔁 月度转班 | "月轮转"人员白/夜互换；**默认月末周末转班**（最后周六起），可切固定日期（1~31 号） |
| 🛏 休息规则 | 无休 / 上六休一（每 7 天休 1 天，从月初滚动）/ 双休（周末休） |
| 🛡 连班保护 | 任何人「夜班→次日白班」（0 小时间隔）自动插一天休息；白班→夜班（16h）允许 |
| 🔥 周末倾斜 | 周六/周日分别设为"繁忙"→ 双休人员该日被叫回并标记**加班** |
| 💤 留守模式 | 低负荷时每天只保留白班 2 人 + 夜班 1 人（名单轮换），其余休息 |
| 📅 跨月连续视图 | 表格跨月连续滚动（本月 / **本月+下月（默认）** / 上月+本月 / 上月+本月+下月），转班前后几天无缝查看；打印跨月时询问视图选择 |
| ✍️ 手工微调 | 点击循环 休→白→夜；<kbd>Shift</kbd>+点击=加班；<kbd>Alt</kbd>+点击=留守；拖拽批量；**右键菜单**（休/请假/清除手动）；自动排班**保留**手工修改 |
| ↩️ 撤销 / 重做 | 点击/拖拽/右键/复制/清手动/转班均可 <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> |
| 📝 请假登记 | 右键 → 事假/病假/年假/其他，格子变灰显示"假"，统计出勤自动排除 |
| 🔍 排班体检 | 一键检查连班、连续上班超限、班次空缺、节假日值班、**轮转夜班偏多**，违规划红框；可**一键自动修复连班** |
| 🏮 节假日标记 | 标记法定假日/停线日，表头 🏮 + 名称，列淡黄高亮；**内置 2026 法定假日一键标记** |
| 📋 复制排班 | 选源人员 📋 → 点目标人员 → 当月排班整体复制（可撤销） |
| 📋 复制到下月 | 本月全部手工修改（请假/调班）一键搬移到下月，轮转班次自动生成（可撤销） |
| 🔎 部门筛选 | 排班表只看 除气/转码 单个部门（统计与导出仍为全部人员） |
| ⏪ 自动快照 | 删除人员 / 导入 / 示例覆盖等不可撤销操作前自动保存完整数据（最近 5 份），工具栏「⏪ 快照」一键恢复 |
| ⚡ 自动闭环 | 切到未排班月份自动引导排班；「⚡ 自动排班」后自动体检，有问题直接弹报告 |
| 📊 月度统计 | 每班次人数 / 加班 / 留守 / **请假** / 出勤天数；按部门分组；人员卡片直接显示本月出勤 |
| 📈 每日人力图 | SVG 双柱图（白/夜），加班红色叠加，周末背景色提示 |
| ⬇ CSV 导出 | 排班表 CSV（**含真实日期+星期行**，Excel 兼容，UTF-8 BOM，请假自动标注）+ **月度统计 CSV（月底报工）** |
| 💾 完整备份 | JSON 备份/恢复全部数据（人员、排班、请假、节假日），换电脑迁移 |
| 🖨 打印 | 横向 A4 打印优化，单元格 22px 紧凑版式 |
| 📱 窄屏适配 | 1100 / 900 / 720 / 480 四档断点，手机平板均可使用 |

## 🚀 使用流程

1. **添加技术员** → 姓名 + 部门 + 班次规则 + 休息规则
2. **设置周末负荷** → 工具栏下拉选择 周六/周日 为"繁忙 / 正常 / 低负荷"
3. **点「⚡ 自动排班」** → 生成当月基线（已含转班、连班保护、周末加班），并自动体检（有问题直接弹报告）
4. **手工微调** → 点击格子 / 拖拽 / 右键菜单（请假、休）；必要时「🔍 体检」检查违规
5. **复制到下月** → 排下月时点「📋 复制到下月」把本月请假/调班搬过去，再自动排班微调
6. **导出 / 打印 / 备份** → 排班表 CSV（含日期）/ 月度统计 CSV 给 Excel，打印贴墙，JSON 备份防丢失；删除/导入前自动存快照，「⏪ 快照」可恢复

## 🔑 快捷键

| 操作 | 效果 |
| --- | --- |
| 点击格子 | 循环切换 休→白→夜（画笔=循环切换时） |
| <kbd>Shift</kbd>+点击 | 切换加班标记 |
| <kbd>Alt</kbd>+点击 | 切换留守标记 |
| 右键格子 | 弹出菜单：休 / 请假（事假/病假/年假/其他）/ 取消请假 / 清除手动 |
| 双击表头日期 | 复制前一天排班到该日（跨月自动衔接） |
| <kbd>1</kbd>~<kbd>6</kbd> | 切换画笔：循环 / 白班 / 夜班 / 休 / 加班 / 留守 |
| <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> | 撤销 / 重做 |
| <kbd>◀</kbd> <kbd>▶</kbd> / <kbd>PgUp</kbd> <kbd>PgDn</kbd> | 切换月份 |
| 拖拽单元格 | 按当前画笔批量填充 |

## 🛠 技术

- **纯静态** · 单文件 `index.html`，无后端、无构建、无依赖
- **离线可用** · 下载 HTML 双击打开即可使用（Chrome 可能要求 `file://` 协议）
- **localStorage** · 人员 / 手工覆盖 / 请假 / 节假日 / 设置 自动保存（数据版本 v7，自动迁移旧数据）
- **GitHub Pages** · 从 `main` 分支根目录部署
